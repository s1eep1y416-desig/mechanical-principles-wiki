# 常见错误

## 结构分析

- 把机架计入活动构件数 $n$。
- 复合铰链只算一个转动副。
- 看见几何重复就删约束，却没有检查它是否真的不增加独立约束。
- 自由度大于零就断言运动确定；还必须检查原动件数是否与自由度相等且布置合理。

## 运动分析

- 未知矢量大小和方向都未知，却直接在速度多边形中画线。
- 混淆法向加速度和切向加速度方向。
- 在存在相对滑动的转动构件上漏掉科氏加速度。
- 用角度制直接进行微分计算，导致数值多出或少了 $\pi/180$。

## 受力与动力

- 摩擦力方向总按外力反向，而不判断相对运动趋势。
- 把达朗贝尔惯性力当成真实接触力。
- 在一般平面运动中只加惯性力，漏掉惯性力偶。
- 用飞轮调节长期平均功率不平衡；飞轮只能平抑周期内波动。

## 机构设计

- 用 Grashof 条件直接判断机构类型，忽略机架选择。
- 把凸轮理论轮廓当作滚子从动件实际轮廓。
- 只检查齿轮模数相等，不检查压力角和参数所在平面。
- 周转轮系直接连乘齿数，没有把角速度换成相对行星架的角速度。
- 只给出唯一机构方案，没有比较动力性能、制造与调整。

## 自检问题

每道题完成后问自己：研究对象是否清楚？正方向是否标在图上？每个方程是否独立？单位是否一致？结果的数量级、方向和极限情况是否合理？
