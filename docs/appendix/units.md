# 单位、符号与换算

<p class="page-lead">
机械原理的计算错误，有很大一部分不是公式错，而是单位没有统一：角速度用了 rpm、长度用了 m、功率用了 W。本页把常用换算和典型取值范围集中在一起，代入数值前先扫一眼。
</p>

## 1. 基本量与 SI 单位

| 量 | 符号 | SI 单位 | 常用工程单位 |
| --- | --- | --- | --- |
| 长度 | $l$ | m | mm、cm |
| 质量 | $m$ | kg | g、t |
| 时间 | $t$ | s | min、h |
| 角度 | $\theta$ | rad | °、′、″ |
| 速度 | $v$ | m/s | mm/s、km/h |
| 加速度 | $a$ | m/s² | mm/s²、g |
| 角速度 | $\omega$ | rad/s | r/min、r/s |
| 角加速度 | $\varepsilon$ | rad/s² | r/min² |
| 力 | $F$ | N | kN、kgf |
| 力矩 | $M$ | N·m | N·mm、kgf·m |
| 功率 | $P$ | W | kW、马力 |
| 转动惯量 | $J$ | kg·m² | kg·mm²、g·cm² |
| 频率 | $f$ | Hz | — |

## 2. 角度换算

$$
180^\circ=\pi\ \mathrm{rad},\qquad 1^\circ=\frac{\pi}{180}\ \mathrm{rad}\approx0.01745\ \mathrm{rad}
$$

$$
1\ \mathrm{rad}=\frac{180^\circ}{\pi}\approx57.2958^\circ
$$

- 分、秒：$1^\circ=60'$，$1'=60''$；
- 常见角度弧度值：$30^\circ=\pi/6$，$45^\circ=\pi/4$，$60^\circ=\pi/3$，$90^\circ=\pi/2$，$180^\circ=\pi$；
- 压力角 $20^\circ\approx0.3491\ \mathrm{rad}$，$\sin20^\circ\approx0.3420$，$\cos20^\circ\approx0.9397$，$\tan20^\circ\approx0.3640$。

## 3. 转速与角速度

$$
\omega=\frac{2\pi n}{60}\quad(\mathrm{rad/s}),\qquad n=\frac{60\omega}{2\pi}\quad(\mathrm{r/min})
$$

其中 $n$ 的单位是 r/min。常用换算：

| 转速 $n$ (r/min) | 角速度 $\omega$ (rad/s) |
| --- | --- |
| 60 | 6.283 |
| 100 | 10.472 |
| 300 | 31.416 |
| 750 | 78.540 |
| 1000 | 104.720 |
| 1500 | 157.080 |
| 3000 | 314.159 |

::: warning 最常见单位错误
把 $n=1450\ \mathrm{r/min}$ 直接当成 $\omega=1450\ \mathrm{rad/s}$ 代入 $v=\omega r$，结果会放大 $2\pi/60\approx9.55$ 倍。
:::

## 4. 功率、转速与转矩

$$
T=9550\frac{P}{n}\quad(\mathrm{N\cdot m}),\qquad T=9.55\times10^6\frac{P}{n}\quad(\mathrm{N\cdot mm})
$$

其中 $P$ 用 kW，$n$ 用 r/min。机械原理中飞轮、等效力矩计算常用 N·m；强度计算常用 N·mm，代入前先统一。

## 5. 力与质量

- $1\ \mathrm{kgf}=9.80665\ \mathrm{N}$；
- $1\ \mathrm{N}=0.10197\ \mathrm{kgf}$；
- 工程近似取 $g=9.8\ \mathrm{m/s^2}$，$1\ \mathrm{kgf}\approx9.8\ \mathrm{N}$；
- 惯性力 $F_I=ma$，质量 kg、加速度 m/s²，结果才是 N。

## 6. 转动惯量

- 均质圆盘绕中心轴：$J=\frac12 mr^2$；
- 均质细杆绕中点：$J=\frac{1}{12}ml^2$；
- 均质圆环：$J=mr^2$；
- 平行轴定理：$J_O=J_C+md^2$；
- 单位换算：$1\ \mathrm{kg\cdot m^2}=10^6\ \mathrm{kg\cdot mm^2}$。

以下为教学与一般工程中的**典型范围**，不是标准强制值；具体设计以教材、手册和课程要求为准。

| 参数 | 典型范围/取值 | 说明 |
| --- | --- | --- |
| 齿轮标准压力角 $\alpha$ | $20^\circ$ | 我国标准；少数用 $25^\circ$ |
| 正常齿齿顶高系数 $h_a^*$ | 1.0 | 短齿 0.8 |
| 正常齿顶隙系数 $c^*$ | 0.25 | 短齿 0.3 |
| 标准直齿轮最少齿数 $z_{\min}$ | 17 | $\alpha=20^\circ$、$h_a^*=1$ |
| 齿轮重合度 $\varepsilon_\alpha$ | 1.1–1.4 以上 | 一般要求 $>1$，动力传动常要求更大 |
| 四杆机构最小传动角 $\gamma_{\min}$ | $\ge40^\circ$ | 高速重载取更大 |
| 凸轮推程许用压力角 | $30^\circ$–$40^\circ$ | 回程可放宽 |
| 滚子半径 $r_r$ | $\le0.8\rho_{\min}$ | 外凸理论廓线 |
| 行程速比系数 $K$ | 1.0–2.0 | $K$ 越大急回越明显 |

| 当量摩擦系数 $f_v$（轴颈） | 0.01–0.1 | 与配合、润滑有关 |

## 8. 单位检查清单

代入公式前，按顺序检查：

1. 长度是不是 mm？齿轮公式中的 $d,a$ 必须与 $m$ 同单位；
2. 角度是不是 rad？$\sin$、$\cos$ 的括号里必须是弧度（计算器切到 RAD）或明确用角度模式；
3. 角速度是不是 rad/s？不要直接把 r/min 代入 $v=\omega r$；
4. 功率是不是 kW？$T=9550P/n$ 中 $P$ 用 kW；
5. 力矩是不是 N·m 或 N·mm？与长度单位匹配；
6. 传动比有没有符号？周转轮系代入时必须带正负号；
7. 效率有没有大于 1？效率小于 1 才正常，出现大于 1 通常是把输入/输出搞反了。

::: tip 量纲检查法
把单位当作代数量一起运算。例如 $v=\omega r$ 的单位是 $\mathrm{rad/s}\cdot\mathrm{m}=\mathrm{m/s}$；如果算出 $\mathrm{m/min}$，就说明转速没有换成 rad/s 或时间单位没有统一。
:::
