## 怎么用这张表

1. **先看章节**：公式不是孤立的，回到对应章节看假设、符号和适用条件；
2. **再对单位**：长度 mm、角度 °/rad、角速度 rad/s、功率 kW、转速 r/min，是最容易出错的地方；
3. **最后看边界**：标准齿轮还是变位齿轮？定轴轮系还是周转轮系？对心从动件还是偏置？条件变了，公式也要变。

:::

## 六条最常考的计算链

### 自由度计算

```text
画运动简图 → 数活动构件 n → 数低副 p_L、高副 p_H
          → 处理复合铰链（p_L = m−1）
          → 剔除局部自由度、虚约束
          → F = 3n − 2p_L − p_H
          → 与 原动件数 W 比较
```

### 速度/加速度分析

```text
已知原动件运动 → 选速度比例尺 → 列 v_C = v_B + v_CB
              → 作速度多边形 → 求各点速度、角速度
              → 列 a_C = a_B + a_CB^n + a_CB^t
              → 有牵连转动时补哥氏加速度 a_k = 2ω₁v_B2B1
              → 作加速度多边形 → 求加速度、角加速度
```

### 四杆机构设计（按 K）

```text
给定 K → θ = 180°(K−1)/(K+1)
      → 选固定铰链位置 → 作极位夹角 θ
      → 定曲柄/摇杆长度 → 检查格拉肖夫条件
      → 检查最小传动角 γ_min
      → 完成尺度综合
```

### 凸轮设计

```text
确定推杆运动规律（s-v-a 曲线）
→ 选基圆半径 r₀ 与偏距 e
→ 校核压力角 α ≤ [α]
→ 确定滚子半径 r_r < 0.8ρ_min
→ 反转法求理论廓线与实际廓线
→ 校核运动失真与强度
```

### 渐开线齿轮几何

```text
选 m、z₁、z₂ → d = mz
            → d_a、d_f、p、s、e
            → 标准中心距 a = m(z₁+z₂)/2
            → 啮合角 α′、重合度 ε_α
            → 校核根切、齿顶厚、干涉
```

### 轮系传动比

```text
判断轮系类型 → 定轴：i = (−1)^m ∏z从/∏z主
            → 周转：加 −n_H 转化为定轴，i_1n^H = (n₁−n_H)/(n_n−n_H)
            → 复合：先划分基本轮系，再联立
            → 代入已知转速，求未知转速/传动比
```
