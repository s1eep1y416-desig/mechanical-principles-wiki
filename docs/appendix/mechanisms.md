# 常用机构选型速查

<p class="page-lead">
机构选型不是“背出所有机构”，而是先写清运动要求，再按运动形式、传动比、精度、速度、载荷和成本逐项筛选。本页把第 8–12 章的常用机构放在一起比较。
</p>

## 1. 一张总表

| 机构 | 输入 → 输出运动 | 传动比/行程 | 效率 | 优点 | 局限 | 典型场合 |
| --- | --- | --- | --- | --- | --- | --- |
| 连杆机构 | 转动 → 往复/摆动/复杂平面运动 | 取决于杆长 | 较高 | 承载大、耐冲击、结构简单 | 运动规律受限、有死点 | 内燃机、压力机、剪切机、雨刷 |
| 凸轮机构 | 转动 → 任意往复运动规律 | 取决于轮廓 | 中 | 可精确实现任意运动规律 | 高副易磨损、行程不宜过大 | 内燃机配气、自动机送料、印刷机 |
| 齿轮机构 | 转动 → 转动（定传动比） | 准确、范围大 | 高 | 传动比准确、效率高、寿命长 | 制造安装要求高、有噪声 | 减速器、机床、汽车变速器 |
| 蜗杆传动 | 转动 → 转动（大传动比） | 大（可达 80 以上） | 较低 | 结构紧凑、传动比大、可自锁 | 滑动摩擦、发热、效率低 | 起重、分度、电梯、减速器 |
| 带传动 | 转动 → 转动（挠性） | 较大 | 较高 | 缓冲吸振、过载打滑保护、远距离 | 传动比不准确、需张紧 | 电机输出、风机、机床 |
| 链传动 | 转动 → 转动（啮合） | 较大 | 较高 | 平均传动比准确、耐恶劣环境 | 瞬时速度波动、噪声、需润滑 | 自行车、输送机、农机 |
| 棘轮机构 | 摆动/往复 → 单向间歇转动 | 齿距×齿数 | 中 | 结构简单、可实现单向/双向 | 冲击大、噪声、精度低 | 千斤顶、扳手、送料 |
| 槽轮机构 | 连续转动 → 间歇转动 | 槽数决定 | 中 | 运动平稳、结构简单 | 转角不可调、有冲击 | 电影放映机、自动机分度 |
| 不完全齿轮 | 连续转动 → 间歇转动 | 齿数比 | 较高 | 停歇时间可设计、承载大 | 冲击、制造复杂 | 自动机、计数器 |
| 凸轮间歇机构 | 连续转动 → 间歇转动 | 轮廓决定 | 中 | 运动规律可设计、高速平稳 | 凸轮制造复杂 | 高速分度、包装机 |
| 摩擦轮 | 转动 → 转动（摩擦） | 连续可调 | 较低 | 无级变速、过载保护 | 传动比不准确、发热 | 无级变速器、压力机 |
| 螺旋机构 | 转动 → 直线移动 | 导程决定 | 中（可自锁） | 增力大、能自锁、精确 | 效率低、行程有限 | 千斤顶、丝杠、夹具 |
| 组合机构 | 多种运动组合 | 由组合决定 | 取决于组成 | 可兼顾大行程、复杂规律 | 设计分析复杂 | 自动机、机器人、专用设备 |

## 2. 按运动要求选型

### 连续转动 → 往复移动

1. **曲柄滑块机构**：结构简单、承载大；行程 $s=2r$，速度不恒定；
2. **凸轮 + 推杆**：可规定任意运动规律，适合精确送料、配气；
3. **齿轮齿条**：行程可很长，速度均匀，定位精度高；
4. **螺旋机构**：增力大、可自锁，适合低速重载与精确定位。

### 连续转动 → 往复摆动

1. **曲柄摇杆机构**：结构简单，可设计急回特性；
2. **凸轮 + 摆杆**：运动规律可设计，适合高速轻载；
3. **摆动导杆机构**：传力好、摆角大；
4. **齿轮 + 连杆组合**：可兼顾摆角与急回。

### 连续转动 → 间歇转动

1. **槽轮机构**：结构简单、分度准确度中等，适合中低速；
2. **棘轮机构**：适合单向间歇、角度可调，冲击较大；
3. **不完全齿轮**：承载大、停歇时间可设计，冲击较大；
4. **凸轮间歇机构**：高速平稳，但凸轮设计与制造复杂。

### 连续转动 → 大传动比

1. **蜗杆传动**：一级即可获得很大传动比，可自锁，效率低；
2. **行星轮系**：结构紧凑、效率高，传动比范围大；
3. **多级齿轮传动**：效率高、精度高，但体积和重量大；
4. **摆线针轮 / 谐波传动**：大传动比、小体积（第 11 章拓展）。

### 连续转动 → 运动合成/分解

- **差动轮系**：两个输入合成一个输出，或一个输入分解为两个输出；
- **行星轮系**：可实现变速、换向、分路；
- **凸轮连杆组合**：实现复杂运动规律与相位协调。

## 3. 按性能指标选型

| 指标 | 优先选择 | 说明 |
| --- | --- | --- |
| 传动比准确 | 齿轮、蜗杆、链（平均） | 带传动有弹性滑动，不准确 |
| 传动比大 | 蜗杆、行星轮系、少齿差 | 效率与体积需权衡 |
| 效率高 | 齿轮、连杆、链 | 蜗杆、螺旋效率低 |
| 承载大 | 连杆、齿轮、凸轮（低速） | 高副接触应力限制凸轮承载 |
| 高速平稳 | 齿轮、凸轮（无冲击规律）、平衡好的连杆 | 需校核惯性力与振动 |
| 可自锁 | 蜗杆（单头）、螺旋、斜面 | 自锁常伴随低效率 |
| 过载保护 | 带传动、摩擦轮 | 打滑保护电机与后续机构 |
| 远距离传动 | 带、链 | 齿轮、凸轮适合近距离 |
| 成本低 | 连杆、带、链 | 凸轮、精密齿轮成本高 |
| 精度高 | 齿轮、凸轮、螺旋 | 制造与安装精度是关键 |

## 4. 选型决策树

```text
需要什么输出运动？
├─ 连续转动
│  ├─ 传动比准确？ → 齿轮 / 蜗杆 / 链
│  ├─ 传动比很大？ → 蜗杆 / 行星轮系
│  ├─ 需要缓冲/远距离？ → 带传动
│  └─ 需要无级变速？ → 摩擦轮 / 带式无级变速
├─ 往复移动/摆动
│  ├─ 运动规律要求严格？ → 凸轮
│  ├─ 行程大、承载大？ → 曲柄滑块 / 连杆
│  ├─ 需要自锁/增力？ → 螺旋
│  └─ 高速轻载？ → 凸轮（无冲击规律）
├─ 间歇运动
│  ├─ 高速平稳？ → 凸轮间歇机构
│  ├─ 结构简单、中低速？ → 槽轮
│  ├─ 单向、角度可调？ → 棘轮
│  └─ 大承载、长停歇？ → 不完全齿轮
└─ 复杂运动/多自由度
   ├─ 运动规律可分解？ → 组合机构
   ├─ 需要编程/柔性？ → 机器人机构
   └─ 需要协同多执行构件？ → 凸轮连杆组合 / 行星轮系
```

## 5. 选型后的校核清单

选定机构只是开始，还要做以下校核：

- **运动校核**：行程、摆角、速度、加速度是否满足工艺要求；
- **传力校核**：压力角、传动角、死点、自锁；
- **动力校核**：惯性力、平衡、飞轮、速度波动；
- **结构校核**：尺寸、干涉、安装、润滑、密封；
- **精度校核**：传动误差、回差、磨损后的精度保持；
- **经济性**：制造难度、标准件比例、维护成本。

::: warning 选型不是“越复杂越好”
能用简单机构实现的，不要用组合机构；能用标准件的，不要非标定制。复杂度会带来设计、制造、装配、维护和可靠性的一系列成本。
:::
