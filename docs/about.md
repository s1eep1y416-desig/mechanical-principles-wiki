# 关于本站

<p class="about-lead">
一个以《机械原理》（第九版）三篇十四章为骨架的独立学习知识库。目标不是替代教材，而是把教材读薄、把知识连成网。
</p>

## 为什么做这个站

机械原理教材信息密度高：机构简图、运动方程、受力图、公式和工程案例交织在一起。传统笔记按页记录，复习时很难快速回答“这个公式防的是什么问题”“这个方法什么时候会失效”。

本站尝试用类似 [OI Wiki](https://oi-wiki.org/) 的开放文档方式组织内容：

- 左侧按“绪论 → 三篇十四章 → 附录”导航，右侧显示本页目录；
- 全文搜索，支持关键词定位；
- 公式独立成卡，可复制 LaTeX；
- 每章附易错点与工程直觉，章节页标注教材页码；
- 25 张机构示意图与运动线图，以及 13 个可操作的机构实验；重点齿轮、链轮、连杆图按几何约束计算为 SVG；
- 深浅色主题、移动端适配、打印样式；
- 学习进度保存在浏览器本地。

## 参考与致谢

内容框架参照：

- 西北工业大学机械原理及机械零件教研室 编著，孙桓、葛文杰 主编：《机械原理》（第九版），高等教育出版社，2021。
- 教材配套的《机械原理学习指南》《机械原理作业集》等辅导资料（仅作框架参考，未复制内容）。

本站正文为独立撰写的学习笔记，不收录教材 PDF、扫描件、原文段落和插图。教材中的标准表格、图表、完整推导与例题，请以正式出版的第九版教材为准。

## 技术实现

- [VitePress](https://vitepress.dev/) 1.6 / Vue 3
- `markdown-it-mathjax3`（正文公式）
- [KaTeX](https://katex.org/)（公式卡片）
- 本地全文搜索，无后端
- 全部图示为手写内联 SVG，不依赖图表库

## 内容边界与免责声明

本站仅供学习与复习使用，不替代正式教材、课程教学与工程计算书。机构分析、机构设计与工程计算的正确性，须由学习者按教材、国家标准和实际工况复核；涉及实际机械设计时，应由具备资质的设计人员完成完整计算与校核。

如果你发现公式、符号或表述有误，欢迎在后续接入仓库后提交修订。工程计算的正确性永远优先于排版。
