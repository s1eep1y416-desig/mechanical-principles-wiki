# 第 12 章　其他常用机构

> 教材页码：329–362。本章强调按输出运动、精度、速度、载荷和维护要求选型。

## 12.1 间歇运动机构

| 机构 | 典型输出 | 特点与限制 |
|---|---|---|
| 棘轮 | 单向步进 | 结构简单、步距可调，冲击噪声明显 |
| 槽轮 | 周期转位与停歇 | 定位规律明确，进入退出存在加速度变化 |
| 不完全齿轮 | 周期转动与停歇 | 承载较好，需处理啮入啮出冲击 |
| 凸轮式间歇机构 | 指定运动规律 | 动力性能好，制造精度要求高 |

槽轮的运动系数表示一个循环中运动时间所占比例。槽数、圆销数和几何尺寸要同时满足运动时间、强度与干涉条件。

## 12.2 摩擦轮传动机构

理想情况下，接触点切向速度相等：

$$\omega_1r_1=\omega_2r_2$$

实际传动存在弹性滑动和打滑，所以瞬时传动比不严格恒定。能传递的圆周力受法向压紧力和摩擦系数限制：

$$F_t\le fN$$

优点是平稳、结构简单、过载可打滑保护；缺点是压紧力增大轴承载荷，传动精度和效率受接触状态影响。

## 12.3 带有挠性元件的传动机构

### 带传动

带传动适合较大中心距，运行平稳、能缓冲吸振。紧边与松边拉力满足欧拉关系的理想形式：

$$\frac{F_1}{F_2}=e^{f\alpha}$$

弹性滑动不可避免，整体打滑则是过载或张紧不足导致的失效。

### 链传动

链传动平均传动比准确，无弹性滑动，但链节绕链轮形成多边形效应，使瞬时速度周期波动。增加链轮齿数、减小节距有助于降低波动。

### 绳传动

绳传动适合提升、牵引和远距离传递，设计要检查弯曲疲劳、卷筒直径、层绕和防脱槽。

## 12.4 组合机构

组合方式包括串联、并联、叠加和封闭组合。每个子机构应明确输入输出接口，再检查：

1. 总自由度和运动确定性；
2. 各执行件的相位协调；
3. 误差、间隙与柔度累积；
4. 动力峰值和共振；
5. 调整、润滑和维护可达性。

组合机构能让一个子机构负责运动变换，另一个负责停歇、放大或误差补偿。

## 12.5 含有某些特殊元器件的广义机构

液压、气动、电磁、压电、形状记忆材料和柔性元件可与刚性机构组合。此时“运动副”不一定是传统接触副，模型还需描述介质压缩性、磁力、材料迟滞或柔性变形。

选型不应只看能否实现位移，还要比较带宽、精度、输出力、能耗、环境适应性与控制复杂度。

::: tip 选型顺序
先按输出运动、停歇、精度、速度和载荷筛选，再比较尺寸、噪声、制造和维护。
:::
