# 第 3 章　平面机构的运动分析

> 教材页码：55–81。由已知输入求各构件的位置、角速度、角加速度以及关键点的速度和加速度。

## 3.1 机构运动分析的任务、目的和方法

运动分析的依赖关系是 **装配位置 → 速度 → 加速度**。位置决定几何方向，速度描述瞬时运动关系，加速度为惯性载荷计算提供数据。开始前应标明输入位移、角速度和角加速度，并区分不同装配支路。

## 3.2 用图解法作机构的运动分析

### 速度瞬心法

两个作平面相对运动的刚体，在某一瞬时可看作绕一个速度为零的点相对转动。若机构含 $N$ 个构件（含机架），瞬心总数为

$$K=\frac{N(N-1)}{2}$$

直接相连构件的瞬心通常由运动副确定；其余瞬心可用三心定理求出：三个彼此作平面运动的构件，其三个瞬心位于同一直线上。

若构件瞬时绕 $P$ 转动：

$$\frac{v_A}{v_B}=\frac{PA}{PB}$$

瞬心法适合求速度，不能直接求加速度。

### 相对速度矢量

同一刚体上两点 $A,B$ 满足

$$\vec v_B=\vec v_A+\vec v_{BA},\qquad
\vec v_{BA}=\vec\omega\times\vec r_{BA}$$

$\vec v_{BA}$ 垂直于 $AB$。画速度多边形时，先确定各矢量方向，再由交点确定未知大小。

### 相对加速度矢量

$$\vec a_B=\vec a_A+\vec a_{BA}^{n}+\vec a_{BA}^{t}$$

$$a_{BA}^{n}=\omega^2r_{BA},\qquad a_{BA}^{t}=\alpha r_{BA}$$

法向分量沿 $BA$ 指向相对转动中心；切向分量垂直于构件。若点沿正在转动的构件相对滑动，还要加入科氏加速度：

$$\vec a_C=2\vec\omega\times\vec v_r$$

可将相对速度 $\vec v_r$ 沿牵连角速度方向旋转 $90^\circ$ 判断其方向。

### 微型例题

曲柄 $OA=0.10\text{ m}$ 以 $20\text{ rad/s}$ 匀速转动：

$$v_A=\omega OA=2.0\text{ m/s},\qquad
a_A^n=\omega^2OA=40\text{ m/s}^2$$

$v_A$ 垂直于 $OA$，$a_A^n$ 指向 $O$；匀速转动时 $a_A^t=0$。

## 3.3 用解析法作机构的运动分析

对平面闭链先写位置矢量闭合方程

$$\sum_k \vec r_k=0$$

四杆机构可写成：

$$\vec r_1+\vec r_2-\vec r_3-\vec r_4=0$$

投影到 $x,y$ 方向得到两个标量方程。位置方程对时间一次求导得到速度方程，二次求导得到加速度方程。三角方程常有多解，必须用装配支路和运动连续性筛选。

### 数值验证

1. 回代位置闭合方程，残差接近零；
2. 用有限差分检验解析速度、加速度；
3. 检查极限位形附近是否出现速度比突变；
4. 角度使用弧度，单位保持一致。

::: warning 易错点
未知矢量若大小和方向都未知，不能在速度多边形中直接画出；科氏加速度只在“相对滑动 + 承载构件转动”同时存在时出现。
:::
