# 第 3 章　平面机构的运动分析

> 教材页码：55–81。目标是由已知输入求各构件的位置、速度和加速度。

## 分析链

位置是速度分析的几何基础，速度又是加速度分析的基础。应先求解装配位置，并注意同一输入角可能对应不同装配支路。

## 相对速度方程

同一刚性构件上两点 $A,B$ 满足

$$\vec v_B=\vec v_A+\vec v_{BA},\qquad \vec v_{BA}=\vec\omega\times\vec r_{BA}$$

其中 $\vec v_{BA}$ 垂直于 $AB$。图解法的关键不是测量长度，而是先给每个矢量确定方向。

## 相对加速度方程

对同一转动构件：

$$\vec a_B=\vec a_A+\underbrace{\vec a_{BA}^{n}}_{\omega^2 r\，指向转动中心}+\underbrace{\vec a_{BA}^{t}}_{\alpha r\，垂直构件}$$

移动副上存在相对滑动且承载构件同时转动时，还要加入科氏加速度

$$\vec a_C=2\vec\omega\times\vec v_r$$

## 解析法

先写位置矢量闭合方程，再对时间求导得到速度和加速度方程。求导前应统一坐标系，角度函数用弧度。

::: warning 易错点
法向加速度的方向是“由该点指向相对转动中心”，切向加速度方向才由角加速度正负确定。
:::
