# 第 9 章　凸轮机构及其设计

> 教材页码：228–257。凸轮能实现复杂输出规律，但高副接触带来磨损、接触应力和高速冲击问题。

## 9.1 凸轮机构的应用、分类和选型

按凸轮形状可分盘形、移动和圆柱凸轮；按从动件运动可分直动与摆动；按端部形状可分尖顶、滚子和平底从动件。

| 类型 | 优点 | 主要限制 |
|---|---|---|
| 尖顶从动件 | 理论轮廓清楚 | 接触应力大，只适合轻载低速 |
| 滚子从动件 | 摩擦、磨损较小 | 需检查滚子半径和曲率 |
| 平底从动件 | 受力和润滑较好 | 轮廓设计方法不同，可能偏磨 |

选型应同时考虑运动规律、载荷、速度、尺寸、加工和润滑。

## 9.2 推杆的运动规律

一个循环通常分为推程、远休止、回程和近休止。若凸轮角速度恒定：

$$v=\omega\frac{ds}{d\varphi},\qquad
a=\omega^2\frac{d^2s}{d\varphi^2},\qquad
j=\omega^3\frac{d^3s}{d\varphi^3}$$

| 规律 | 边界连续性 | 动力特性 |
|---|---|---|
| 等速 | 端点速度突变 | 刚性冲击，不宜高速 |
| 等加速等减速 | 速度连续、加速度突变 | 柔性冲击 |
| 简谐 | 速度连续，端点加速度有限 | 常用于中速 |
| 摆线 | 位移、速度、加速度连续 | 高速性能较好 |

高速设计不仅要看位移，还要检查速度、加速度和跃度的连续性。

## 9.3 凸轮轮廓曲线的设计

反转法给整个机构附加与凸轮角速度大小相等、方向相反的公共转动，使凸轮相对静止，再按位移规律确定从动件各位置，其包络线就是轮廓。

- 尖顶从动件：尖顶轨迹就是实际轮廓；
- 滚子从动件：滚子中心轨迹是理论轮廓；
- 平底从动件：各位置平底直线族的包络为轮廓。

## 9.4 凸轮机构基本尺寸的确定

### 压力角

压力角是从动件受力方向与速度方向的夹角。压力角增大会使侧向力、导轨摩擦和变形增加。增大基圆通常能减小压力角，但会增大机构尺寸。

### 滚子半径与曲率

滚子半径过大时，实际轮廓可能出现尖点或失真。对外凸理论轮廓，要使实际轮廓曲率半径保持为正，并留出制造余量。

### 偏置量

偏置直动从动件可改善某一行程的压力角，但往往使推程和回程的受力不对称，应按主要工作行程优化。

## 9.5 凸轮机构的分析与反求设计

已知实际轮廓和基圆位置，可以反求从动件位移规律：

1. 按凸轮转角离散轮廓；
2. 求接触几何与从动件位置；
3. 得到 $s(\varphi)$；
4. 用平滑方法求导得到速度、加速度；
5. 检查压力角、曲率和接触连续性。

直接对含测量噪声的离散位移做二次、三次差分会放大噪声，应先拟合或使用解析样条。

## 9.6 高速凸轮机构简介

高速时要考虑从动件质量、弹簧、阻尼、接触刚度和间隙。若法向接触力降为零，可能发生跳跃；重新接触时会产生冲击。设计中应控制峰值加速度和跃度，并校核固有频率、预紧力和接触应力。
