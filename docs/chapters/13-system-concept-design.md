# 第 13 章　机械系统的方案设计

> 教材页码：365–386。本章从“分析给定机构”转向“由功能需求综合机械系统”。

## 13.1 概述

方案设计的核心不是先挑熟悉的机构，而是先把需求写成可验证的功能与运动指标。一个方案应说明能量如何输入、运动如何变换、工作对象如何处理，以及各执行机构怎样协调。

## 13.2 机械工作原理的拟定

把总功能分解成子功能，并为每个子功能寻找不同物理效应。例如“分离物料”可采用筛分、离心、气流或几何限位。工作原理决定能量形式和核心动作，先于具体机构选型。

建议记录：

- 输入对象、初始状态和允许变化；
- 输出对象、目标状态和验收指标；
- 能量来源与环境条件；
- 安全、成本、空间和维护约束。

## 13.3 执行构件的运动设计和原动机的选择

先定义执行构件的轨迹、位移、速度、加速度、停歇、节拍和相位，再决定原动机。

| 原动机 | 适合特点 | 设计注意 |
|---|---|---|
| 异步电机 | 连续、稳定转动 | 调速范围与启动特性 |
| 伺服电机 | 可编程位置速度 | 峰值转矩、惯量匹配 |
| 液压缸 | 大推力直线运动 | 泄漏、温升和控制精度 |
| 气缸 | 快速往复、结构简单 | 压缩性、末端冲击 |

额定功率之外还要检查峰值转矩、启动、制动和工作制。

## 13.4 机构的选型和变异

根据运动类型建立候选库：

- 连续转动 → 往复移动：曲柄滑块、凸轮、滚珠丝杠；
- 连续转动 → 摆动：曲柄摇杆、凸轮、槽轮；
- 精确传动比：齿轮、同步带；
- 间歇转位：槽轮、分割凸轮、伺服直驱。

通过改变机架、运动副、构件长度或组合方式形成变异方案。每次变异后都要重新检查自由度、干涉和传力性能。

## 13.5 机构的组合

多个执行件应在时间和空间上协调。运动循环图可用横轴表示一个工作周期，用区段表示各执行件的工作、回程和停歇。

组合后还要检查输入功率峰值是否叠加。把两个高负载动作错相，可能在不改变平均功率的情况下降低电机峰值转矩。

## 13.6 机械系统方案的拟定

完整方案至少包含：

1. 功能分解与工作原理；
2. 执行构件运动规律；
3. 机构运动简图和自由度；
4. 原动机与传动链；
5. 一个周期的运动协调；
6. 关键尺寸、载荷和性能估算；
7. 风险、失效与安全措施。

## 13.7 机械系统方案拟定举例

以“间歇输送并压印”为例：

- 输送子功能：槽轮、分割凸轮或伺服带；
- 压印子功能：曲柄滑块、肘杆或气缸；
- 协调要求：输送完全停止后压头才下行；
- 评价重点：定位精度、压印力、节拍、换型和安全防护。

至少形成两套方案，再用加权评分和关键约束淘汰。若某方案不满足安全或空间硬约束，不应靠其他高分补偿。

## 13.8 现代机械系统发展情况简介

现代系统更强调传感、驱动、机构和控制共同设计。直驱电机可减少传动链，电子凸轮可替代部分机械凸轮，但断电安全、实时性、传感器故障和软件验证成为新的设计内容。

### 方案评价矩阵

| 指标 | 示例问题 |
|---|---|
| 功能满足度 | 输出轨迹和节拍是否达标 |
| 运动与动力性能 | 压力角、冲击、峰值转矩是否可接受 |
| 制造装配 | 公差、加工设备、装配调整是否可实现 |
| 运维 | 易损件是否可换、润滑点是否可达 |
| 安全 | 故障时是否进入安全状态 |
| 成本 | 全生命周期成本是否合理 |
