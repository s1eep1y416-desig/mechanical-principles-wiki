# 第 13 章　机械系统的方案设计

> 教材页码：365–386。由“分析给定机构”转向“综合新的机构系统”。

## 方案形成链

<PrincipleDiagram type="scheme" title="从需求到机构方案" caption="每一步都应保留多个候选方案；过早锁定机构类型，会缩小解空间。" />

## 1. 明确功能

把总功能分解为可验证的子功能，写清输入、输出、工况和约束。例如“搬运工件”应进一步转化为抓取、提升、平移、定位和释放。

## 2. 设计输出运动

确定输出构件的轨迹、位移、速度、加速度、停歇和节拍，再选择原动机及其运动形式。输出规律是机构选型的依据。

## 3. 机构选型与变异

用功能原理目录提出候选机构，通过改变机架、运动副、构件形状或组合方式形成变异方案。每个方案都需再次检查自由度和运动确定性。

## 4. 组合与协调

多执行机构需要在时间和空间上协调。可用运动循环图表达各执行件在一个周期内的工作区间、停歇区间和相位关系。

## 5. 多指标评价

建议至少比较：功能满足度、运动精度、动力性能、尺寸质量、制造装配、调整维护、成本和安全。评分权重应来自任务需求，而不是为偏好的方案补理由。

::: tip 方案记录
保留淘汰方案及淘汰原因。它能证明选择过程，也便于需求变化时快速回退。
:::
