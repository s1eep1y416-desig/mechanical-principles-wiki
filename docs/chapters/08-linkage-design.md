# 第 8 章　连杆机构及其设计

> 教材页码：175–227。连杆机构以低副连接，承载能力好；设计重点是类型、运动特性与尺度综合。

## 8.1 连杆机构及其传动特点

优点是面接触、耐磨、易润滑、适合传递较大载荷，还能通过不同杆长实现多种轨迹。局限是运动规律通常为非线性，高速时会有惯性载荷，多杆机构的误差与间隙也会累积。

## 8.2 平面四杆机构的基本类型及应用

铰链四杆机构按连架杆能否整周转动分为双曲柄、曲柄摇杆和双摇杆。改变机架可得到不同倒置机构；把转动副演化为移动副可得到曲柄滑块、导杆等机构。

| 机构 | 输入/输出特征 | 典型应用 |
|---|---|---|
| 曲柄摇杆 | 转动 → 摆动 | 搅拌、送料 |
| 双曲柄 | 转动 → 转动 | 平行四边形联动 |
| 双摇杆 | 摆动 → 摆动 | 车辆转向近似机构 |
| 曲柄滑块 | 转动 ↔ 往复移动 | 活塞机械 |
| 导杆机构 | 转动 → 往复摆动/移动 | 插床、急回装置 |

## 8.3 平面四杆机构的基本特性

### 曲柄存在条件

设最短杆 $s$、最长杆 $l$，其余两杆 $p,q$。存在整转副的几何条件为

$$s+l\le p+q$$

机构类型还取决于哪一杆作为机架：

- 最短杆固定：双曲柄；
- 最短杆的邻杆固定：曲柄摇杆；
- 最短杆的对边固定：双摇杆；
- 不满足杆长条件：任取机架通常都是双摇杆。

### 急回特性

极位夹角为 $\theta$、曲柄匀速时，行程速比系数常写为

$$K=\frac{180^\circ+\theta}{180^\circ-\theta}$$

$K>1$ 表示回程平均速度更高。急回可缩短空行程时间，但会提高加速度和惯性载荷。

### 压力角与传动角

压力角 $\alpha$ 是作用力方向与从动件速度方向之间的夹角，传动角 $\gamma=90^\circ-\alpha$。传动角过小会导致有效力分量小、运动副反力大，甚至出现卡滞。

### 死点

当连杆与从动连架杆共线时，驱动力对从动件转轴的力矩可能为零。死点可用于夹紧保持，也可能使机构难以启动；飞轮、并联机构或错相布置可帮助越过死点。

## 8.4 平面四杆机构的设计

常见尺度综合任务包括：

1. 实现两连架杆若干对应位置；
2. 实现连杆若干精确位置；
3. 使连杆点近似通过给定轨迹；
4. 满足急回、传动角和空间尺寸要求。

图解法直观，解析法便于优化。有限个精确点之间仍存在结构误差，因此应在整个工作区间检查最大误差，而不只看精确点。

### 按行程速比设计

由给定 $K$ 先求极位夹角：

$$\theta=180^\circ\frac{K-1}{K+1}$$

再结合摆角、机架位置和曲柄极位几何确定杆长。设计完成后仍要检查最小传动角和干涉。

## 8.5 平面多杆机构

增加基本杆组可得到六杆、八杆等机构，实现更复杂轨迹、停歇或多输出。多杆机构设计应注意：

- 自由度仍与原动件数匹配；
- 各级误差、间隙和柔度会传递；
- 支路和奇异位形增多；
- 求解常需数值闭环与优化。

## 8.6 空间连杆机构简介

空间连杆机构的构件不再局限于平行平面，常含球面副、圆柱副或空间转动副。空间机构能实现复杂姿态，但自由度、装配和干涉分析更难，通常借助坐标变换、旋量或数值仿真。
