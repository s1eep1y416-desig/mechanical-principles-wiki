# 第 1 章　绪论

> 教材页码：1–12。关键词：机器、机构、构件、零件、运动链。

## 四个基本概念

| 概念 | 关注点 | 例子 |
|---|---|---|
| 机器 | 变换或传递能量、物料、信息并完成有用功 | 内燃机、机床 |
| 机构 | 传递或变换运动与力 | 曲柄滑块、齿轮机构 |
| 构件 | 机构中的运动单元，可以由多个零件刚接组成 | 连杆总成 |
| 零件 | 制造单元 | 轴、齿轮、螺栓 |

“构件”按运动关系划分，“零件”按制造划分。同一构件可能由多个零件装配而成。

## 课程主线

机械原理可归纳为四个连续问题：机构由什么组成？给定输入后怎样运动？运动时受到哪些力？怎样反过来设计满足任务的机构？

## 与机械设计的衔接

机械原理确定运动方案和机构参数，机械设计继续确定材料、结构尺寸、强度、寿命、制造和装配。实际工程中两者会迭代，而不是严格串行。

::: warning 易错点
“机器一定比机构复杂”不是定义。是否为机器取决于它是否完成有用机械功或能量、物料、信息的变换；复杂度不是判据。
:::
