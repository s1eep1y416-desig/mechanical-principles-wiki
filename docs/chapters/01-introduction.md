# 第 1 章　绪论

> 教材页码：1–12。本章先建立“机器—机构—构件—零件”的层级，再明确整门课程解决什么问题。

## 1.1 本书研究的对象及内容

机械系统把能量、物料或信息变成预期的运动与功能。

| 层级 | 定义重点 | 典型问题 |
|---|---|---|
| 机器 | 完成有用功或实现能量、物料、信息的变换 | 包装机怎样送料、封口和切断 |
| 机构 | 构件组成的可动系统，用来传递或变换运动与力 | 连续转动怎样变成往复运动 |
| 构件 | 机构中的独立运动单元，可由多个零件刚接组成 | 连杆总成整体怎样运动 |
| 零件 | 制造单元 | 轴、齿轮、螺钉如何加工 |

“构件”按相对运动划分，“零件”按制造划分。若轴与齿轮固连且没有相对运动，在运动分析中可视为同一构件。

课程内容可以压缩为四条主线：

1. **结构分析**：机构由什么组成，是否具有确定运动；
2. **运动分析**：给定输入后，位置、速度和加速度是多少；
3. **力与动力分析**：外力、摩擦和惯性作用怎样传递；
4. **机构综合**：怎样从功能和运动要求反求机构类型与尺寸。

## 1.2 学习机械原理课程的目的

- **分析能力**：画简图、算自由度、建立运动关系、画受力图；
- **设计能力**：根据轨迹、停歇、节拍和传动比选择机构；
- **评价能力**：比较压力角、效率、自锁、平衡和速度波动；
- **表达能力**：用统一符号、参考系和图示说明方案。

机械原理先回答“怎样实现所需运动”，机械设计再回答“零件怎样做得可靠、耐用、可制造”。两者在工程中会反复迭代。

## 1.3 机械原理课程的学习方法

**真实装置 → 机构简图 → 自由度 → 位置 → 速度/加速度 → 受力/动力 → 方案评价**

| 要素 | 要回答的问题 |
|---|---|
| 研究对象 | 是点、构件、杆组还是整机 |
| 参考系 | 相对机架、行星架还是运动坐标系 |
| 正方向 | 位移、角速度和力矩以什么方向为正 |
| 适用条件 | 平面、刚体、匀速输入、忽略摩擦等假设是否成立 |

::: tip 建议
先画图、标方向，再列方程。结果不合理时，优先检查模型、参考系和正负号。
:::

## 1.4 机械原理学科发展现状简介

现代机构学已扩展到机器人、并联机构、柔顺机构、可重构机构和机电协同设计。仿真和优化能快速比较方案，但自由度、约束、摩擦、柔性和驱动假设仍需正确建模。
