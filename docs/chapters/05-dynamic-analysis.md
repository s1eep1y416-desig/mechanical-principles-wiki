# 第 5 章　机械的动力分析

> 教材页码：113–126。高速机械中，惯性载荷可能与工作载荷同量级，不能继续按纯静力平衡处理。

## 5.1 机械动力分析的任务、目的及方法

动力分析把运动学结果转化为惯性作用，用于计算运动副动态载荷、原动机转矩、振动与冲击，并为平衡、飞轮和强度设计提供输入。

直接法使用牛顿—欧拉方程：

$$\sum\vec F=m\vec a_S,\qquad \sum M_S=J_S\alpha$$

动静法引入惯性力和惯性力偶，把动力问题改写成形式上的平衡问题。

## 5.2 构件惯性力的确定

$$\vec F_I=-m\vec a_S,\qquad M_I=-J_S\alpha$$

| 构件运动 | 惯性作用 |
|---|---|
| 纯平动 | 只有过质心的 $\vec F_I$ |
| 绕质心定轴转动 | 质心不加速，只有 $M_I$ |
| 一般平面运动 | 同时有 $\vec F_I$ 与 $M_I$ |

当 $\vec F_I\ne0$ 时，可将力与力偶合成为一条偏离质心的惯性力作用线，偏距大小为

$$h=\frac{|M_I|}{|F_I|}$$

合成后仍要保留正确的偏置方向，使其对质心的力矩与原惯性力偶相同。

::: warning
惯性力是达朗贝尔方法中引入的等效量，不是另一个物体施加的真实接触力。
:::

## 5.3 不考虑摩擦时机构的动态静力分析

1. 由位置分析得到各构件姿态；
2. 由运动分析求 $\vec a_S$ 和 $\alpha$；
3. 对每个构件施加 $\vec F_I$、$M_I$；
4. 从已知载荷的末端构件开始分组隔离；
5. 求运动副反力，再回推驱动构件；
6. 用整机功率或能量关系复核驱动力矩。

动静法方程为

$$\sum \vec F+\vec F_I=0,\qquad
\sum M_S+M_I=0$$

### 微型例题：匀加速滑块

质量 $m=4\text{ kg}$ 的滑块向右加速度为 $3\text{ m/s}^2$：

$$F_I=ma=12\text{ N}$$

惯性力方向向左。若忽略摩擦和其他水平外载荷，驱动力应为 $12\text{ N}$ 向右。

### 功率复核

理想约束反力不做功时：

$$P_{in}+\sum P_{external}=\frac{dT}{dt}$$

逐构件受力求得的驱动力若不满足整机功率平衡，通常说明惯性力方向、力矩正负或某个构件加速度有误。
