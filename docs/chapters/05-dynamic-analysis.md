# 第 5 章　机械的动力分析

> 教材页码：113–126。高速机械中，惯性载荷常与外载荷同量级。

## 达朗贝尔原理

对质量为 $m$、质心加速度为 $\vec a_S$ 的刚体，引入惯性力

$$\vec F_I=-m\vec a_S$$

对质心再引入惯性力偶

$$M_I=-J_S\alpha$$

把它们与真实外力共同列入平衡方程，这种方法称为动静法。惯性力是计算上引入的等效量，不是另一个物体施加的真实相互作用力。

## 一般平面运动构件

惯性作用可由过质心的 $\vec F_I$ 与惯性力偶 $M_I$ 表示，也可在满足等效条件时合成为偏离质心的一条惯性力作用线。

## 分析流程

1. 由运动分析求质心加速度和构件角加速度；
2. 计算各构件惯性力与惯性力偶；
3. 隔离构件或杆组，加入外力与运动副反力；
4. 按选定正方向列 $\sum F_x=0$、$\sum F_y=0$、$\sum M=0$；
5. 反查所得驱动力或平衡力是否与假设方向一致。

::: warning 易错点
若构件只作定轴转动，仍可能同时存在质心惯性力和惯性力偶；只有质心位于转轴等特殊情况才可进一步简化。
:::
