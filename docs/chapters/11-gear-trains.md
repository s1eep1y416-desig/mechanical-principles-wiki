# 第 11 章　齿轮系及其设计

> 教材页码：304–328。先判断轴线是否随行星架运动，再选择公式。

## 定轴轮系

所有齿轮轴线固定时，各级传动比连乘。中间惰轮通常不改变传动比大小，但会影响输出转向和空间布置。

## 周转轮系

至少一个齿轮轴线随行星架运动。给整个轮系附加角速度 $-\omega_H$，可把它转化为相对行星架的定轴轮系。对典型太阳轮 1、内齿圈 3 和行星架 $H$：

$$\frac{\omega_1-\omega_H}{\omega_3-\omega_H}=-\frac{z_3}{z_1}$$

## 复合轮系

复合轮系应先拆成若干定轴子轮系和基本周转轮系，分别列方程，再利用同轴刚接构件角速度相同等连接条件联立求解。

## 功能与设计

轮系可以实现大传动比、换向、变速、运动合成和运动分解。行星轮数与齿数还要满足同心、装配和邻接条件，单靠传动比不能确定可装配方案。

::: warning 符号错误
不要用“外啮合次数”直接给整个周转轮系判断正负。应在转化轮系中写相对角速度公式，再由求解结果解释真实转向。
:::
