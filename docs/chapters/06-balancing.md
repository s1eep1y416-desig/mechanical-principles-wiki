# 第 6 章　机械的平衡

> 教材页码：127–145。平衡的目标是减小惯性力在机架上的周期性作用。

## 刚性转子的静平衡

各偏心质量位于同一近似平面时，静平衡条件为矢量和

$$\sum_i m_i\vec r_i=0$$

静平衡可在一个校正面内完成，解决的是合离心惯性力为零。

## 刚性转子的动平衡

轴向分布不可忽略时，还需使离心惯性力形成的合力偶为零：

$$\sum_i m_i\vec r_i=0,\qquad \sum_i m_i\vec r_i l_i=0$$

一般至少需要两个校正面。

## 平面机构平衡

往复或摆动构件的惯性力随位置变化，完全平衡往往增加质量、尺寸或惯量。工程上常在机架振动、附加质量和结构空间之间做部分平衡。

::: tip 判断
薄盘类转子通常先考虑静平衡；长转子、宽转子或高速转子通常需要动平衡。最终要求应由转子形状、转速和允许振动共同确定。
:::
