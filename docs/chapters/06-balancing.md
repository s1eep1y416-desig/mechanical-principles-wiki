# 第 6 章　机械的平衡

> 教材页码：127–145。平衡用于减小惯性力和惯性力偶传到轴承、机架与基础的周期载荷。

## 6.1 机械平衡的目的及内容

不平衡会引起振动、噪声、轴承载荷和疲劳，也会降低测量与加工精度。平衡不是消除构件自身惯性，而是重新分配质量，使系统对机架的合惯性作用减小。

- **刚性转子平衡**：工作转速下弹性变形可忽略；
- **平面机构平衡**：多个往复、摆动构件共同产生时变惯性力；
- 高速柔性转子还涉及临界转速与振型，超出刚性转子模型。

## 6.2 刚性转子的平衡

### 静平衡

各偏心质量近似位于同一回转平面时：

$$\sum_i m_i\vec r_i=0$$

可在一个校正面加配重或去重，平衡质量满足

$$m_b\vec r_b=-\sum_i m_i\vec r_i$$

### 动平衡

轴向分布不可忽略时，还需令合惯性力偶为零：

$$\sum_i m_i\vec r_i=0,\qquad
\sum_i m_i\vec r_i l_i=0$$

一般需要两个不同轴向位置的校正面。

| 情况 | 合惯性力 | 合惯性力偶 |
|---|---:|---:|
| 未平衡 | 可能不为零 | 可能不为零 |
| 静平衡 | 0 | 可能不为零 |
| 动平衡 | 0 | 0 |

薄盘、低速转子常先考虑静平衡；长转子、宽转子或高速转子通常要求动平衡。

## 6.3 平面机构的平衡

若系统总质心固定，对机架的合惯性力可显著降低：

$$\sum_i m_i\vec r_{S_i}=\text{常矢量}$$

完全平衡可能增加配重、尺寸、总质量和驱动力矩，配重自身还可能增大惯性力偶。因此工程上常采用部分平衡，只削弱主要谐波或最显著的往复惯性力。

### 平衡设计流程

1. 计算各构件质心加速度；
2. 求合惯性力和合惯性力偶随输入角变化；
3. 找出主导阶次和关键转速；
4. 选择配重位置、质量或对称机构；
5. 比较平衡前后支承力、驱动力矩和新增质量；
6. 用实测振动验证制造误差后的效果。
