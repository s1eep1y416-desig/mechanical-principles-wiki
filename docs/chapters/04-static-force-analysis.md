# 第 4 章　平面机构的静力分析

> 教材页码：82–112。研究低速或忽略惯性力时的机构受力。

## 从隔离体图开始

每次只隔离一个构件或构件组，保留外力、重力、驱动力、约束反力和摩擦力。两个构件之间的作用力与反作用力大小相等、方向相反，作用在不同物体上。

## 运动副中的摩擦

滑动摩擦满足库仑模型

$$F_f\le fN,\qquad \tan\varphi=f$$

极限摩擦力作用时，合反力相对法线偏转摩擦角 $\varphi$。转动副中可用摩擦圆描述总反力作用线的位置，但方向仍需由相对转动趋势判断。

## 机械效率

在稳定运转、同一时间区间内，效率可写为

$$\eta=\frac{W_r}{W_d}=\frac{P_r}{P_d}$$

其中 $W_d$ 是输入功，$W_r$ 是有用输出功。串联系统各级效率相乘；并联功率流应按功率分别求和，不能简单相乘。

## 自锁

自锁指机构在某些受力与摩擦条件下，驱动力撤去后阻力不能反向驱动机构。它取决于几何与摩擦条件，不能简单等同于“效率低”。常见判断方法是：反行程所需驱动力是否与假定方向矛盾，或反行程效率是否不大于零。

::: danger 建模边界
库仑摩擦是理想模型。高速、润滑显著、材料黏弹性明显时，摩擦系数可能随速度、温度和载荷变化。
:::
