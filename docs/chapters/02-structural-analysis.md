# 第 2 章　机构的结构分析

> 教材页码：13–54。先把真实机器抽象为正确的运动模型。

## 机构简图

机构简图只表达构件数、运动副类型、运动尺寸和相对位置。与运动无关的真实轮廓、材料和紧固细节应省略。

## 平面机构自由度

若所有构件作平面运动，活动构件数为 $n$，低副数为 $P_L$，高副数为 $P_H$，则常用公式为

$$F=3n-2P_L-P_H$$

若存在公共约束、虚约束或局部自由度，应先识别并按课程采用的修正规则处理，不能只机械代数。

## 三类高频陷阱

### 复合铰链

$k$ 个构件在同一轴线上构成复合铰链，相当于 $k-1$ 个转动副。

### 局部自由度

滚子绕自身轴线的转动若不影响输出运动，属于局部自由度；分析主运动时应排除其影响。

### 虚约束

重复而不增加独立约束的运动副属于虚约束。删除它不会改变机构实际运动，但其成立通常依赖特定几何条件。

## 组成原理

把机构分解为原动件、机架和基本杆组，有助于判断结构级别并形成新的机构。基本杆组本身自由度为零，接入原动件系统后不改变原有自由度。

::: tip 检查顺序
先数构件，再逐个标运动副；检查复合铰链、局部自由度、虚约束，最后才代入公式。
:::
