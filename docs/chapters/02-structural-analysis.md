# 第 2 章　机构的结构分析

> 教材页码：13–54。目标是把真实机器化成正确的运动模型，并判断机构能否按预期运动。

## 2.1 机构结构分析的内容及目的

结构分析先回答四个问题：有多少构件？怎样连接？有几个独立运动？给定多少个原动件后运动才能确定？结果用于检查概念方案、建立运动模型，也用于把复杂机构拆成基本杆组。

## 2.2 机构的组成、分类及其简图表达

两个构件直接接触并保留一定相对运动的连接称为**运动副**。

| 类型 | 接触形式 | 平面问题中常见约束数 | 例子 |
|---|---|---:|---|
| 低副 | 面接触 | 2 | 转动副、移动副 |
| 高副 | 点或线接触 | 1 | 齿轮啮合、凸轮接触 |

机构简图只保留构件数、运动副、运动尺寸、相对位置和原动件。先沿传动路线识别独立运动单元，再标运动副，最后用规定符号连接。

## 2.3 机构的运动确定性及其自由度分析

平面内一个自由构件有 3 个自由度。若活动构件数为 $n$，低副数为 $P_L$，高副数为 $P_H$：

$$F=3n-2P_L-P_H$$

<PrincipleDiagram type="mobility" title="四杆机构的自由度" caption="3 个活动构件、4 个转动低副，F=3×3−2×4=1。配置 1 个原动件后运动确定。" />

- $F>0$ 且原动件数等于 $F$：一般可获得确定运动；
- 原动件数少于 $F$：仍有未指定运动；
- 原动件数多于 $F$：输入可能互相冲突；
- $F\le0$：通常不能形成预期机构运动，或模型存在特殊约束。

### 四类高频修正

1. **复合铰链**：$k$ 个构件在同一轴线形成 $k-1$ 个转动副；
2. **局部自由度**：滚子自转等不影响输出的运动应剔除；
3. **虚约束**：删除后不改变机构运动的重复约束；
4. **特殊几何约束**：平行、共线等条件可能使约束相关。

::: warning
“看起来对称”不等于虚约束。必须证明该约束可由其他约束和特定几何条件推出。
:::

### 微型例题：曲柄滑块机构

有曲柄、连杆、滑块 3 个活动构件，3 个转动副和 1 个移动副：

$$F=3\times3-2\times4=1$$

以曲柄作为一个原动件时，滑块运动确定。

## 2.4 平面机构的组成原理、结构分类及分析与综合

机构可拆成**机架 + 原动件 + 基本杆组**。基本杆组自身自由度为零，接入已有机构后不改变系统自由度。结构分析从完整机构向基本杆组分解；结构综合则反向组合。

分解时从远离原动件的一端尝试，拆下杆组后剩余部分仍应是机构。结构级别反映求解耦合程度，不表示强度或先进程度。

## 2.5 机构的变换原理及其结构创新设计

- **改变机架**：同一运动链选择不同构件固定；
- **运动副替代**：用高副、低副或等效杆组保持运动关系；
- **尺度变化**：让某杆长度趋于无穷，把转动副演化为移动副；
- **扩大运动副**：把转动副半径扩大，形成偏心轮等结构；
- **增减杆组**：在不改变所需自由度的前提下生成多杆方案。

## 2.6 机构结构的型综合及其合理设计

型综合确定构件和运动副，尺度综合确定长度与位置。合理结构应满足：

1. 自由度与原动件数匹配；
2. 不产生非预期过约束；
3. 输出运动符合任务；
4. 可以装配且有足够运动空间；
5. 受力、制造、调整和维护可接受。
