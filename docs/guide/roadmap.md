# 学习路线

<p class="page-lead">
同一本教材，不同的使用目的需要不同的读法。这里给出三条路线：第一次系统学习、期末/考研复习、课程设计与创新实践。每条路线都标出“必须掌握”和“可以后补”的内容。
</p>

## 路线 A · 系统学习

适合第一次学《机械原理》的读者。目标是建立“组成 → 运动 → 力 → 设计”的完整链条，而不是背零散公式。

| 阶段 | 章节 | 必须掌握 | 可以后补 |
| --- | --- | --- | --- |
| 入门 | 第 1 章 | 课程地图、机械/机构/机器的区别 | 学科前沿 |
| 结构 | 第 2 章 | 运动副、运动简图、自由度计算、杆组 | *型综合 |
| 运动 | 第 3 章 | 瞬心、速度/加速度图解法 | 解析法编程 |
| 静力 | 第 4 章 | 摩擦角/摩擦圆、效率、自锁 | 复杂机构力分析技巧 |
| 动力 | 第 5 章 | 惯性力、动态静力分析 | 杆组法手算速度 |
| 平衡与运转 | 第 6–7 章 | 静/动平衡、等效模型、飞轮 | *弹性构件 |
| 连杆 | 第 8 章 | 类型判定、急回、压力角、图解法设计 | 空间连杆 |
| 凸轮 | 第 9 章 | 运动规律、反转法、压力角 | 高速凸轮 |
| 齿轮 | 第 10 章 | 渐开线、几何计算、重合度、变位概念 | *动力学 |
| 轮系 | 第 11 章 | 定轴、周转、复合轮系传动比 | 行星轮系效率 |
| 其他机构 | 第 12 章 | 棘轮、槽轮的运动特点与选型 | 广义机构 |
| 系统与机器人 | 第 13–14 章 | 方案设计流程、机器人位姿/雅可比 | D-H 详细推导 |

建议节奏：每章 2–3 小时，读完正文后合上书，用一张 A4 纸写出“本章解决什么问题、核心公式、一个例子、两个易错点”。写不出来的地方就是需要回读的地方。

::: tip 每章只抓三件事
1. 这一章的研究对象和基本假设；
2. 一个能贯穿全章的核心方程或几何关系；
3. 这个方法在什么情况下会失效。
:::

## 路线 B · 考前复习

适合已经学过一遍、需要在两周内恢复到考试状态的读者。不要从头按页读，按**题型**反查。

### 第一轮：公式与条件（2–3 天）

打开 [核心公式速查](/appendix/formulas)，按类别过一遍。每个公式只问三件事：

- 符号各是什么、单位是什么；
- 适用条件是什么（标准齿轮？定轴轮系？对心从动件？）；
- 最常见的代入错误是什么。

### 第二轮：六类高频计算（5–7 天）

| 题型 | 重点章节 | 常见失分点 |
| --- | --- | --- |
| 自由度计算 | [第 2 章](/chapters/02-structural-analysis) | 复合铰链少数、局部自由度未剔除、虚约束误判 |
| 速度/加速度分析 | [第 3 章](/chapters/03-kinematic-analysis) | 哥氏加速度方向、影像定理用错、方程数不足 |
| 四杆机构 | [第 8 章](/chapters/08-linkages) | 格拉肖夫条件与机架选择、极位夹角、传动角位置 |
| 凸轮 | [第 9 章](/chapters/09-cams) | 运动规律分段、反转法方向、压力角公式符号 |
| 齿轮几何与重合度 | [第 10 章](/chapters/10-gears) | 齿顶圆压力角、啮合角、变位后中心距 |
| 轮系传动比 | [第 11 章](/chapters/11-gear-trains) | 周转轮系符号、复合轮系划分、惰轮 |

### 第三轮：错题与概念（3–4 天）

- 把做错的题按“概念错 / 公式错 / 计算错 / 单位错”分类；
- 概念错回到章节正文，公式错回到公式卡，计算错限时重做；
- 考前最后一天只看 [易错点汇总](/appendix/formulas) 和各章 `## 易错点`，不再开新题。

## 路线 C · 课程设计 / 创新设计

适合课程设计、机械创新大赛、毕业设计起步。目标是把“分析”转成“设计”。

### 第 1 步：功能与运动需求

- 明确输入运动（电机转速、连续/间歇）与输出运动（行程、摆角、速度规律、精度）；
- 写出一句话的“运动功能”：例如“把连续转动变为每分钟 30 次的间歇送料，每次行程 80 mm”；
- 画运动循环图（时间—位移），标出工作段、空回段、停歇段。

### 第 2 步：机构选型

参考 [常用机构选型速查](/appendix/mechanisms)，按“运动形式 → 传动比/行程 → 精度 → 速度 → 载荷 → 成本”逐项筛选。常见组合：

- 连续转动 → 往复移动：曲柄滑块、凸轮+推杆、齿轮齿条；
- 连续转动 → 间歇转动：槽轮、棘轮、不完全齿轮；
- 连续转动 → 大传动比：齿轮系、蜗杆、行星轮系；
- 任意运动规律：凸轮机构或连杆机构组合。

### 第 3 步：尺度综合

- 连杆机构：按行程速比系数、连杆位置或两连架杆对应位置设计；
- 凸轮机构：先选运动规律，再定基圆半径、滚子半径和偏距；
- 齿轮机构：选模数、齿数、变位系数，校核重合度与根切；
- 轮系：分配传动比，校核同心、装配、邻接条件。

### 第 4 步：分析与校核

- 运动校核：行程、速度、加速度是否满足要求；
- 传力校核：压力角/传动角、死点位置、自锁风险；
- 动力校核：惯性力、平衡、速度波动、飞轮；
- 结构校核：尺寸干涉、安装、润滑、制造工艺。

### 第 5 步：方案评价

从功能实现、运动性能、动力性能、结构工艺、成本、可靠性六个维度列表比较 2–3 个方案，选综合最优而不是单项最优。

::: warning 课程设计最常见的三个坑
1. 先画机构再补运动要求，导致行程或速度对不上；
2. 只做运动设计，不校核压力角和死点；
3. 忽略装配与制造，图上能画出来、实际装不进去。
:::

## 和其他课程的关系

| 先修/并行课程 | 在本课程中的用处 |
| --- | --- |
| 理论力学 | 静力平衡、运动学、动力学基础 |
| 机械制图 | 机构运动简图、零件图表达 |
| 高等数学 / 线性代数 | 解析法运动分析、矩阵运算、机器人位姿 |
| 机械设计 | 把机构方案落到零件强度、轴承、轴系与结构 |
| 自动控制 / 机器人学 | 第 14 章机器人机构的延伸 |

学完本课程后，可以接着读同目录下的《机械设计知识库》：机械原理回答“怎样实现运动”，机械设计回答“怎样把运动方案变成可靠零件”，两门课合起来才是一台完整的机器。
