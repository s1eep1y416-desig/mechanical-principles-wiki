# 学习路线

## 系统学习

推荐顺序是 **2 → 3 → 4 → 5 → 7 → 6 → 8 → 9 → 10 → 11 → 12 → 13 → 14**。第 6 章平衡放在动力分析之后；若课程按教材顺序授课，直接跟随教材也没有问题。

| 阶段 | 目标 | 完成标志 |
|---|---|---|
| 结构 | 会画简图、算自由度 | 能解释复合铰链、局部自由度和虚约束 |
| 运动 | 会列相对运动方程 | 能从方向条件画出速度、加速度多边形 |
| 力与动力 | 会画隔离体图 | 能区分静力、惯性力、摩擦与自锁 |
| 机构设计 | 会由要求选机构 | 能说明尺度、压力角与运动品质的取舍 |
| 方案综合 | 会比较多套方案 | 能从功能、运动、动力、制造和成本评价 |

## 考试复习

先做四条计算链：

1. 构件数与运动副数 → 自由度 → 运动确定性；
2. 位置图 → 速度方程 → 加速度方程；
3. 齿数与构件角速度 → 定轴/周转轮系传动比；
4. 驱动力矩与阻力矩 → 最大盈亏功 → 飞轮转动惯量。

然后用[常见错误](/appendix/common-errors)检查符号、方向和适用条件。

## 方案设计

从“输出件需要怎样运动”开始，不先指定某一种机构。为每个功能至少提出两种方案，再比较运动精度、动力性能、尺寸、制造、调整和安全性。
