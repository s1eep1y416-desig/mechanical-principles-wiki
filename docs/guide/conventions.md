# 符号与约定

| 符号 | 含义 | 常用单位 |
|---|---|---|
| $n$ | 活动构件数 | — |
| $P_L, P_H$ | 低副数、高副数 | — |
| $F$ | 机构自由度 | — |
| $\omega, \alpha$ | 角速度、角加速度 | rad/s、rad/s² |
| $v, a$ | 线速度、线加速度 | m/s、m/s² |
| $M_d, M_r$ | 驱动力矩、阻力矩 | N·m |
| $J$ | 转动惯量 | kg·m² |
| $f, \varphi$ | 摩擦系数、摩擦角 | —、rad 或 ° |
| $m, z, \alpha$ | 齿轮模数、齿数、压力角 | mm、—、° |

## 正负号

- 先在图上规定角速度、力矩和坐标轴正方向，再写方程。
- 齿轮外啮合常用负号表示转向相反；内啮合转向相同。
- 周转轮系公式中的角速度必须相对同一个固定参考系。
- 题目若只问传动比大小，可最后取绝对值，但中间推导仍应保留符号。

## 图示颜色

本站示意图统一使用：橙色表示输入或主动量，蓝色表示中间构件或已知矢量，绿色表示输出或合成量，虚线表示辅助线、轨迹或参考圆。
