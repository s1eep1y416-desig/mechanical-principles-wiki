# 符号与约定

<p class="page-lead">
机械原理的公式不难，难的是符号太多、同名符号在不同章节含义不同。本页统一约定本站的符号、单位与正负号规则；遇到与教材不一致的地方，以教材上下文为准，并在章节里单独说明。
</p>

## 1. 单位约定

本站默认采用国际单位制（SI），工程尺寸用 mm。公式中若使用其他单位，会在公式旁注明。

| 量 | 符号 | 默认单位 | 备注 |
| --- | --- | --- | --- |
| 长度、杆长、中心距 | $l,a,r$ | mm | 齿轮几何全部用 mm |
| 角度、转角、摆角 | $\theta,\varphi,\psi,\delta$ | °（度） | 公式需要弧度时写 rad |
| 角速度 | $\omega$ | rad/s | 与 rpm 换算：$\omega=2\pi n/60$ |
| 角加速度 | $\varepsilon$ | rad/s² | 避免与压力角 $\alpha$ 混淆 |
| 速度 | $v$ | m/s | 图解法中常按比例尺换算 |
| 加速度 | $a$ | m/s² | 重力加速度取 $g=9.8\ \mathrm{m/s^2}$ |
| 力 | $F,G,N$ | N | — |
| 力矩 | $M,T$ | N·m | 小力矩可用 N·mm，须注明 |
| 质量 | $m$ | kg | 齿轮章中 $m$ 为模数，按上下文区分 |
| 转动惯量 | $J$ | kg·m² | 飞轮转动惯量 $J_F$ |
| 功率 | $P$ | kW | 与 W 换算：$1\ \mathrm{kW}=10^3\ \mathrm{W}$ |
| 转速 | $n$ | r/min | 与角速度换算：$\omega=2\pi n/60$ |
| 效率 | $\eta$ | — | 无量纲，$0<\eta<1$ |
| 传动比 | $i$ | — | 无量纲，带正负号表示转向关系 |
| 齿数 | $z$ | — | 整数 |
| 模数 | $m$ | mm | 标准值 |
| 压力角 | $\alpha$ | ° | 标准齿轮 $\alpha=20^\circ$ |
| 传动角 | $\gamma$ | ° | $\gamma=90^\circ-\alpha$ |
| 螺旋角 | $\beta$ | ° | 斜齿轮 |
| 分度圆锥角 | $\delta$ | ° | 锥齿轮 |
| 行程速比系数 | $K$ | — | $K\ge 1$ |
| 速度不均匀系数 | $\delta$ | — | 与锥齿轮 $\delta$ 不同章使用，注意上下文 |

::: warning 两个高频混淆
1. **$\alpha$**：在第 8、9 章通常指压力角；在某些运动方程中又可能表示角加速度。本站统一用 $\varepsilon$ 表示角加速度。
2. **$m$**：第 6、7 章是质量；第 10、11 章是模数。看到 $m$ 先看章节。
:::

## 2. 正负号约定

### 传动比

- 外啮合圆柱齿轮：转向相反，$i_{12}<0$；
- 内啮合圆柱齿轮：转向相同，$i_{12}>0$；
- 圆锥齿轮、蜗杆传动：传动比大小按齿数比，方向用箭头判断，不强行套正负号；
- 周转轮系：$n_1,n_n,n_H$ 都带正负号，同向为正、反向为负，代入转化机构公式。

### 力与力矩

- 力沿坐标轴正向为正；
- 力矩逆时针为正（平面问题）；
- 惯性力方向与质心加速度方向相反：$\boldsymbol{F}_I=-m\boldsymbol{a}_S$；
- 惯性力矩方向与角加速度方向相反：$M_I=-J_S\varepsilon$；
- 驱动力、驱动力矩做正功；阻力、阻力矩做负功。

### 效率与自锁

- 效率 $\eta=W_r/W_d$，输出功/输入功，恒小于 1；
- 自锁判据：$\eta\le 0$，或驱动力作用线落在摩擦角/摩擦圆内；
- 螺旋副上升时效率 $\eta=\tan\psi/\tan(\psi+\varphi_v)$，$\psi$ 为螺纹升角，$\varphi_v$ 为当量摩擦角。

## 3. 公式书写约定

- 标量用斜体，矢量用粗斜体：$\boldsymbol{v}$、$\boldsymbol{a}$、$\boldsymbol{\omega}$；
- 矩阵用粗体大写：$\boldsymbol{J}$、$\boldsymbol{T}$；
- 单位用正体：$\mathrm{mm}$、$\mathrm{rad/s}$、$\mathrm{N\cdot m}$；
- 函数名正体：$\sin$、$\cos$、$\tan$、$\mathrm{d}$；
- 下标表示对象：$v_{Si}$ 表示构件 $i$ 质心速度，$\omega_i$ 表示构件 $i$ 角速度；
- 上标 $(n)$、$(t)$ 表示法向、切向分量；上标 $H$ 表示系杆（行星架）；
- 瞬心用 $P_{ij}$ 表示构件 $i$、$j$ 的相对瞬心；
- 齿轮参数：$m$ 模数、$z$ 齿数、$\alpha$ 压力角、$h_a^*$ 齿顶高系数、$c^*$ 顶隙系数、$x$ 变位系数；斜齿轮加下标 $n$（法面）、$t$（端面）。

## 4. 图解法约定

- 速度比例尺 $\mu_v=\frac{\text{实际速度}}{\text{图上长度}}$，单位 $\mathrm{(m/s)/mm}$；
- 加速度比例尺 $\mu_a$，单位 $\mathrm{(m/s^2)/mm}$；
- 速度多边形：从极点 $p$ 出发的矢量表示绝对速度，两绝对速度端点连线表示相对速度；
- 加速度多边形：从极点 $p'$ 出发，法向加速度指向圆心，切向加速度垂直于连线；
- 影像定理：同一构件上三点构成的图形与速度/加速度多边形中对应点构成的图形相似，且字母顺序一致。

## 5. 机构简图约定

- 构件用实线表示，机架用斜线或固定符号表示；
- 转动副用小圆圈，移动副用滑块与导轨；
- 高副用接触点/线表示，凸轮与从动件接触处画公法线；
- 原动件用箭头标出运动方向；
- 构件编号 1、2、3……，机架编号常为 4 或单独标注；
- 运动副字母：$A,B,C$ 表示铰链点，$P_{ij}$ 表示瞬心。

## 6. 数值与有效数字

- 中间计算保留 3–4 位有效数字，最终结果按题目要求取 2–3 位；
- 角度精确到分（′）或 0.1°；
- 长度精确到 0.01 mm 或 0.1 mm；
- 传动比、效率保留 3 位小数；
- 计算齿轮几何时，先写公式再代数，避免中间四舍五入导致齿顶圆、中心距对不上。

## 7. 与教材符号的差异

本站尽量沿用第九版教材符号，但为保持一致做了少量统一：

| 本站 | 教材可能写法 | 说明 |
| --- | --- | --- |
| $\varepsilon$ | $\alpha$ | 角加速度；避免与压力角冲突 |
| $p_L,p_H$ | $P_L,P_H$ | 低副数、高副数，小写表示数量 |
| $\varphi_f$ | $\varphi$ 或 $\rho$ | 摩擦角 |
| $f_v$ | $f_v$ | 当量摩擦系数 |
| $n$ | $n$ 或 $\omega$ | 转速用 r/min；角速度用 $\omega$ |

::: tip 遇到符号冲突怎么办
先看公式的上下文和单位：角速度/角加速度看 rad/s、rad/s²；压力角看 °；质量看 kg；模数看 mm。仍不确定时，以教材该节的符号说明为准。
:::
