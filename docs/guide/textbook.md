# 教材目录与页码

<p class="page-lead">
本页按《机械原理》（孙桓、葛文杰主编，第九版，高等教育出版社）的目录整理，方便把站内笔记与纸质书对照。页码为教材正文页码；带 * 的为教材中的拓展小节。
</p>

<TextbookToc />

## 使用说明

- 每一章的开头都标注了教材页码范围，例如“教材 p.013–054”；
- 正文中的 `## 2.1 …` 与教材节号一一对应，带 `（*）` 的小节对应教材中的 * 号内容；
- 页码用于定位，不表示本站逐页复述教材；
- 若使用其他版本（第八版及更早），章节编号差异较大：第九版把力分析拆为第 4 章“静力分析”与第 5 章“动力分析”，并把效率、自锁放入第 4 章。

::: info 第九版的结构变化
第九版将全书重组为三篇：**机构分析基础**（第 2–7 章）、**常用机构设计**（第 8–12 章）、**机械方案设计**（第 13–14 章）。学习时建议按这个顺序建立框架，而不是按旧版笔记的章节顺序拼接。
:::
