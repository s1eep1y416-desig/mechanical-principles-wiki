# 学习指南

机械原理研究的是**机构怎样组成、怎样运动、怎样受力，以及怎样按需求设计**。它与机械设计的分工不同：前者先回答“运动如何实现”，后者进一步回答“零件怎样做得可靠、耐用和可制造”。

## 建议的分析顺序

1. **画机构简图**：保留运动关系，去掉与运动无关的外形细节。
2. **检查自由度**：确认原动件数量与机构自由度相等，运动才确定。
3. **建立运动模型**：先求位置，再求速度和加速度。
4. **画隔离体受力图**：分清外力、约束反力、摩擦力和惯性力。
5. **评价动力性能**：检查效率、自锁、平衡和速度波动。
6. **进入方案综合**：从输出运动倒推机构类型和尺寸。

::: tip 学习原则
每个公式都要同时记录四件事：研究对象、正方向、参考系、适用条件。只记公式而不记模型，是机械原理最常见的失分原因。
:::
