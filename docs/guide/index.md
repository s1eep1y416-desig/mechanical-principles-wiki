# 使用指南

> 这不是教材的电子版，而是一套**按问题组织**的学习笔记。教材负责完整叙述，这里负责建立索引、压缩要点、暴露盲点。

> 需要对照纸质书页码时，打开 [教材目录与页码](/guide/textbook)。

## 先动手观察

打开 [图解与实验](/labs/)，可集中操作 13 个机构实验；实验也嵌入了对应章节。齿轮和链轮可以改变齿数，凸轮可切换运动规律，摩擦、惯性、平衡与飞轮可以改变参数，机械臂可调关节角。

## 这个知识库解决什么问题

《机械原理》第九版全书三篇十四章、四百多页，从机构组成一路讲到机器人机构。初学者常见的困境不是“某个公式没记住”，而是：

- **结构感缺失**：学完连杆、凸轮、齿轮，说不出它们在整台机器里怎样协同；
- **方法混淆**：图解法、解析法、瞬心法各自适合什么场合，什么时候该用哪一个；
- **条件记错**：格拉肖夫条件、曲柄存在条件、重合度、自锁条件，字母都认识，边界一用就错；
- **分析与设计脱节**：会算给定机构的运动，却不会按运动要求反求机构尺寸。

本站把每章压缩成五个层次：

| 层次 | 你会看到 | 目的 |
| --- | --- | --- |
| 问题 | 本章要解决哪类工程问题 | 建立动机 |
| 模型 | 构件、运动副、几何关系、受力 | 知道公式从哪来 |
| 公式 | 核心计算式、符号与单位 | 能算，知道边界 |
| 例 | 一个可手算的完整例题 | 把方法走通 |
| 易错点 | 常见错误、适用条件、与相邻章的关系 | 发现盲点 |

## 全书地图

| 篇 | 章节 | 核心问题 |
| --- | --- | --- |
| 绪论 | 第 1 章 | 机械原理研究什么、怎样学 |
| 第一篇 机构分析基础 | 第 2–7 章 | 机构怎样组成？运动、力、惯性力怎样分析？机器运转是否平稳？ |
| 第二篇 常用机构设计 | 第 8–12 章 | 给定运动要求，怎样设计连杆、凸轮、齿轮、轮系与间歇机构？ |
| 第三篇 机械方案设计 | 第 13–14 章 | 怎样从功能需求走到机构方案？机器人机构怎样分析设计？ |

一条贯穿全书的主线是：

```text
组成（第2章） → 运动（第3章） → 力（第4、5章） → 平衡与运转（第6、7章）
      → 常用机构设计（第8–12章） → 系统方案与机器人（第13、14章）
```

前三章建立“语法”，中间四章建立“力学”，后七章进入“设计”。如果时间有限，至少把第 2、3、8、9、10 章读透：自由度、运动分析、连杆、凸轮、齿轮是课程的主干。

## 三种推荐读法

### 系统学习

从 [第 1 章 绪论](/chapters/01-introduction) 开始，按顺序读第 1–7 章，把机构组成、运动分析、力分析、平衡与运转这条分析链走通；再进入第 8–12 章的机构设计；最后用第 13、14 章收束到系统方案与机器人。

阅读时准备一张纸，每学完一章画一张“这一章解决什么问题、核心公式是什么、边界在哪”的小卡片。

### 考前复习

先打开 [核心公式速查](/appendix/formulas)，按“结构 → 运动 → 力 → 平衡 → 运转 → 连杆 → 凸轮 → 齿轮 → 轮系 → 机器人”的顺序过一遍公式；每遇到一个公式，回到对应章节看它的适用条件和一个例题。

计算题高频模块：

1. 自由度计算（复合铰链、局部自由度、虚约束）；
2. 速度/加速度图解法与解析法；
3. 四杆机构类型判定与急回特性；
4. 凸轮运动规律与压力角；
5. 渐开线齿轮几何与重合度；
6. 轮系传动比（尤其周转轮系与复合轮系）。

### 课程设计 / 创新设计

按 [学习路线中的课程设计路线](/guide/roadmap#课程设计路线) 推进：功能分析 → 执行构件运动设计 → 机构选型 → 机构组合 → 尺度综合 → 运动与动力校核。不要一上来就画机构，先把“输入—输出运动关系”写清楚。

## 符号与单位

全书采用国际单位制，机构和零件的几何尺寸默认用 mm，角度默认用度（°）。公式中常见符号：

- $l$：构件长度，mm；
- $\theta$、$\varphi$：转角、极位夹角，° 或 rad；
- $\omega$：角速度，rad/s；
- $\varepsilon$：角加速度，rad/s²；
- $F$：力，N；$M$：力矩，N·m；
- $n$：构件数或转速（r/min），按上下文区分；
- $z$：齿数；$m$：模数，mm（齿轮章中不是质量）；
- $\alpha$：压力角，°；$\gamma$：传动角，°；
- $i$：传动比；$\eta$：机械效率。

完整对照见 [符号与约定](/guide/conventions) 和 [单位、符号与换算](/appendix/units)。

## 内容边界

本站以《机械原理》（第九版）的**目录结构与知识框架**为参照，正文为独立撰写的学习笔记，不复制教材原文、例题和插图。教材中的标准表格、图表和完整推导，请以正式出版的第九版教材为准。

如果你发现公式、符号或表述有误，欢迎在后续接入仓库后提交修订。工程计算的正确性永远优先于排版。
