# 机械原理知识库

一个独立的 VitePress 学习网站，以《机械原理》第九版的三篇十四章、75 个教材小节为目录骨架，内容为重新组织和撰写的学习笔记，并包含公式条件、原理图、微型例题和章节自测。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

站点源文件在 `docs/`，教材核对记录在 `source-notes/`。原始扫描 PDF 保持在用户的 Apple Books/iCloud 文档目录，不复制进项目。

## 图解与交互

重点章节使用按几何约束生成的 SVG：齿轮、链轮、连杆、速度与受力分析。第 8 章包含曲柄摇杆和曲柄滑块交互实验台。

```bash
npm test # 杆长闭环、速度、链节节距、啮合与凸轮接触验证
```

图解校核与后续建议见 [审查记录](review/2026-10-22-图解与知识审查.md)。动画采用理想刚体运动学模型；齿根与链轮齿顶过渡为教学示意，不作为制造图。
