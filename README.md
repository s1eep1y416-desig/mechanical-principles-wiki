# 机械原理知识库

一个独立的 VitePress 学习网站，以《机械原理》第九版的三篇十四章、75 个教材小节为目录骨架，内容为重新组织和撰写的学习笔记，并包含公式条件、原理图、微型例题和章节自测。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

站点源文件在 `docs/`，教材核对记录在 `source-notes/`。原始扫描 PDF 保持在用户的 Apple Books/iCloud 文档目录，不复制进项目。

## 图解与交互

全站包含 25 张正文图解和 13 个交互实验，统一入口为 [图解与实验](https://s1eep1y416-desig.github.io/mechanical-principles-wiki/labs/)。每个实验也嵌入对应章节，支持暂停、单步、相位调整与放大查看。

实验覆盖齿轮、行星轮系、链轮、凸轮、槽轮、连杆、斜面摩擦、滑块惯性、转子配重、飞轮储能、2R 机械臂、哥氏加速度和工作循环。齿数、升程、运动规律、摩擦系数、转动惯量与关节角等参数会改变图形和数值。

```bash
npm test # 杆长闭环、速度、链节节距、啮合与凸轮接触验证
```

图解校核与后续建议见 [审查记录](review/2026-10-22-图解与知识审查.md)。新增实验的模型条件、验收范围和限制见 [扩充验收记录](review/2026-10-24-交互图解扩充验收.md)。教学模型的假设直接写在图下；齿根与链轮齿顶过渡为示意，不作为制造图。
